Next-Gen Web Document Editor v0.0.1

A Rust + WebAssembly document editor with first-class Arabic / RTL support.

What this is

A document editor whose engine is compiled from Rust to WebAssembly and runs entirely in your browser — no server, no iframe, no vendored binary blobs. Arabic shaping, the Unicode Bidirectional Algorithm, line breaking and A4 page layout were day-one requirements, not afterthoughts.

Phase 1 — proof of concept

This release closes Phase 1: a working engine that loads fonts, shapes Arabic with correct cursive joining, resolves mixed Arabic/English BiDi per line, lays text out on an A4 page with justification, supports editing with undo/redo, and round-trips a .docx file.

Engine size

The WebAssembly artifact is ≈ 1.9 MB — about 12 % of the 15 MiB budget. For comparison, the OnlyOffice WASM blob other editors vendor is 57 MB and cannot be rebuilt from source.

Known limitations

Typing appends at end-of-document (click-to-place caret arrives in Phase 4). Backspace and newline are not yet wired. Kashida justification is a coarse first pass. These are tracked in the phase plans in the repository.
